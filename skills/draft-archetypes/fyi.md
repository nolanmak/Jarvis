# Archetype: FYI forward

## Intent

The user is forwarding something so the recipient is aware, with no action
expected. State plainly that it's just for visibility, give a one-line "why
this matters to you", and explicitly say no reply is needed so it doesn't
generate a return volley. Do not over-explain the forwarded content — the
recipient can read it.

## Exemplars (in the user's voice)

> Forwarding this so you're in the loop — {one_line_why_relevant}. No action
> needed on your end, just wanted you to have it.

> FYI, see below re: {topic}. Flagging since it touches {recipient_concern}.
> Nothing required from you; reach out if you want to dig in.

> Passing this along for visibility. {one_line_why_relevant}. Read at your
> leisure — no response expected.

## Slot hints

- `{topic}` — what the forwarded item is about
- `{one_line_why_relevant}` — why the recipient should care, one sentence
- `{recipient_concern}` — the recipient's area this touches
