# Archetype: Holding-pattern

## Intent

The user can't give a full response yet but wants to acknowledge receipt and
set expectations so the sender isn't left wondering. Confirm you saw it, signal
it matters, and commit to a concrete follow-up time. The whole value is the
specific timeframe — never leave it open-ended ("soon", "later"). Short.

## Exemplars (in the user's voice)

> Got this — thanks. I want to give it a proper read rather than a rushed
> reply, so I'll come back to you with thoughts by {commit_date}.

> Thanks, {sender_first_name}. On my radar. Tied up until {commit_date}; I'll
> have a real answer for you then. Flag me sooner if it gets urgent.

> Received, and this is important — I don't want to shortchange it. Expect a
> full reply from me by {commit_date}.

## Slot hints

- `{commit_date}` — a concrete date or day; never vague
- `{sender_first_name}` — use if known
