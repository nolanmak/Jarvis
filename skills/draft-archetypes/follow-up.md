# Archetype: Follow-up after N days

## Intent

A thread has stalled and the user is re-poking, or the sender is following up
and the user owes a re-engagement. Be brief and low-pressure. Reference the
prior thread concretely so it doesn't read as a generic bump, restate the one
thing you need, and make the next step trivial to take. No guilt, no "just
circling back" filler if it can be avoided.

## Exemplars (in the user's voice)

> Following up on {prior_topic} — still keen to make this work. Is
> {specific_ask} something you can get to this week, or should I check back
> later?

> {sender_first_name}, bumping this in case it slipped — no rush, just want to
> keep it on the radar. Happy to jump on a quick call if that's easier than
> email.

> Quick nudge on {prior_topic}. If now's not a good time, totally fine — just
> let me know when works and I'll follow your lead.

## Slot hints

- `{prior_topic}` — the specific subject of the stalled thread
- `{specific_ask}` — the single concrete thing you're waiting on
- `{sender_first_name}` — use if known
