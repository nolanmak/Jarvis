# Autoship recovery and acceptance

Status recorded November 11, 2026. GitHub PR/issue state and the deployed
controller's current readback take precedence over this dated record.

Repair PRs are ordinary engineering work: review against current main, merge
main into the branch when needed, pass required CI, and merge normally. Do not
rebase or force-push backlog branches. A manual repair merge contributes zero
to the autonomous merge allowance and zero to autonomous acceptance.

Autoship acceptance uses ordinary repository issues selected naturally by the
loop. Retain the original issue, candidate, workflow, model/attempt accounting,
verification, independent review and exact merge evidence. The required path is:

1. Autoship selects an ordinary issue and writes the change.
2. It publishes the PR and verifies the exact candidate.
3. Independent review completes against the bound candidate and contract.
4. Required GitHub checks pass and autoship merges the PR.

A running process, repeated claim, green CI job, delivered status message or
manually merged repair does not establish that full path. Record observed
milestones and blockers; do not restart the canceled benchmark campaign.

Readiness evidence must quote literal immutable source bytes, including comment
markers and line breaks when they occur inside a quote. Correction feedback
preserves bounded previous output and verbatim source excerpts privately; it
does not relax validation or increase the three completed-assessment limit.
`readiness_assessment_invalid / await_readiness_input_change` means those
corrections were exhausted, not that an owner decision is missing. The same
binding cannot make another productive claim, including after a restart or day
change. Changed request, source or environment bindings can retry through normal
admission; owner pauses still apply. Admission also binds GitHub’s freshly read
main SHA and the readiness-policy version, so a retained checkout does not hide
a real upstream change or policy rollout. Bump the shared readiness policy when
changing its correction protocol. General reconciliation remains available.
